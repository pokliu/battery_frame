# 32140 16S2P 电动自行车电池支架（PETG 3D 打印）

为 32 只小鲁 32140 电芯（16S2P）设计的全包式电池支架。它装进内腔 275（高）×220×165 的箱体，每边留 0.5 mm 装配公差。配套 BMS 是 JK-BD6AxxS-8PD。模型由一个参数化的 FreeCAD 脚本生成，改参数后重跑脚本即可。

## 设计概要

- **排布**：35 mm 节距的正方形网格。下面 5 层每层 6 只，顶层 2 只靠右，顶层空出的 4 个电芯位放 BMS。
- **结构**：主体是两端开口的管阵，两端各用一块端盖挡住电芯（Ø24 点焊孔）。端盖用 M4 热熔螺母和 M4×12 盘头螺丝固定。顶部压框把整个支架压到箱盖上，防止上下跳动。
- **串联**：每层 3 组，蛇形串联。B+ 和 B− 都在 B 端，镍片焊在端盖外侧。
- **BMS**：用 M3 热熔螺母装在主体顶部的两根导轨上，外露安装，便于散热。
- **温度探头**：中心电芯的孔壁上有一条 5.5×5 的槽，深 75 mm，探头从 A 端推入，贴在电芯中段。

## 重新生成模型

1. 打开 FreeCAD 1.0 以上版本。
2. 在 Python 控制台里执行下面的代码：

```python
exec(open('/Users/admin/Downloads/battery/battery_holder_v2.py', encoding='utf-8').read())
R = build_all()   # 重建文档「电池支架_v2」，返回校验报告
export_all()      # 导出 STL/、STEP/ 并保存 电池支架_v2.FCStd
```

脚本只会重建 `电池支架_v2` 这个文档，不会改动其他已经打开的文档。`build_all()` 返回的报告里有干涉体积、孔位余量、箱体间隙等数据。改完参数后，先确认干涉全部为 0、间隙都是 0.5，再导出。

常改的参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `hole_d` | 33.6 | 电芯孔径，按试打块的结果改 |
| `m4_d` / `m3_d` | 5.6 / 4.0 | 热熔螺母孔径 |
| `body_len` | 140.5 | 电芯腔长 |
| `nickel_w` | 20.0 | 镍带焊盘宽，用来检查螺丝位有没有压到镍片 |
| `ntc_w` / `ntc_depth` / `ntc_len` | 5.5 / 5 / 75 | 探头槽尺寸 |
| `plate_t` | 2.5 | 端盖挡板厚（受力分析定） |
| `screws` | 每端 15 个 | M4 螺母位列表 |
| `lighten` | True | 是否开 Ø8 减重/通风孔 |

## 装配顺序

1. 往主体两端压入 M4 热熔螺母，往 BMS 导轨压入 M3 热熔螺母。
2. 按极性交替插入电芯。
3. 从 A 端把 NTC 探头推到槽底，线从 A 端端盖的 Ø6 孔穿出。
4. 锁紧两端端盖。
5. 隔着 Ø24 孔点焊镍片，焊采样线，贴青稞纸。
6. 装上 BMS 并接线。
7. 装进箱体，放上压框，盖上箱盖。

详细步骤和串联连接表见 `电池支架v2-需求与进展.md`。
