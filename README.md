# 32140 16S2P 电动自行车电池支架（PETG 3D 打印）

为 32 只小鲁 32140 电芯（16S2P）设计的电池支架（v3）。它装进外框 275（高）×220×165、板厚 0.85 的手工焊接不锈钢箱（内腔约 273.3×218.3×163.3），桶内贴青稞纸。只有底部垫 3 mm 硅胶条；两侧只贴青稞纸，轴向留 5 mm 装配余量（卖家要求，含纸）；顶部不放硅胶，压框顶面到箱盖留 15（让开箱盖紧固螺丝），每条边正中间一个凸台顶住箱盖；前后每边留 1.5。配套 BMS 是 JK-BD6AxxS-8PD。模型由参数化的 FreeCAD 脚本生成，改参数后重跑即可。

## 设计概要

- **排布**：35 mm 节距正方形网格，下面 5 层每层 6 只，顶层 2 只靠右，顶层空出的位置放 BMS。
- **结构**：两端各一片 24 深的电芯座（挡边 1.5，Ø24 点焊孔），中间 95.5 mm 敞开散热。端盖 A 6.1 厚、B 8.7 厚，底板整面，隔着青稞纸顶住箱壁；支撑垫放在电芯之间的星形位上。6 颗 M4×150 内六角螺丝贯穿端盖 A、两片座（Ø14 定位管定距）和端盖 B，螺丝头没入端盖 A 沉孔，另一端拧进端盖 B 的 M4×8×6 热熔螺母。
- **连接片**：0.1 铜 + 0.1 镍，宽 20。6 处用 4 只一排的直条，9 处用 2×2 整块方片。B−、B+ 都在 B 端最上面一层。
- **出线**：端子片从正中间向上延伸成引出片，伸出支架顶面 22 mm，12AWG 在顶面以上锡焊，从压框顶部开口引到箱盖。
- **缓冲**：只有底部两条 3 mm 硅胶条。
- **温度探头**：贴在中心电芯中段，线从 A 座的 Ø6 孔出来。

## 重新生成模型

在 FreeCAD 1.1 的 Python 控制台执行：

```python
exec(open('/Users/admin/Downloads/battery/battery_holder_v3.py', encoding='utf-8').read())
R = build_all()   # 重建文档「电池支架_v3」，返回校验报告
export_all()      # 导出 STL/、STEP/ 并保存 电池支架_v3.FCStd
```

常改的参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `hole_d` | 33.6 | 电芯孔径，按试打块结果改 |
| `lip_t` | 1.5 | 挡边厚（FEA 定） |
| `liner_t` | 0.3 | 青壳纸厚，量到实际值后改 |
| `box_outer` / `sheet_t` / `box_inner` | 220×275×165 / 0.85 / None | 箱外框、板厚；有实测内腔时填 `box_inner` |
| `gap_x` | 1.5 | 前后每边空隙（影响外壁厚） |
| `z_clear_total` | 5.0 | 轴向装配余量合计（含两侧青稞纸） |
| `end_rubber_t` / `top_rubber_t` / `fit_clear` | 0 / 0 / 15 | 两侧、顶部硅胶垫厚（0 = 不放）；压框顶面到箱盖空隙 |
| `insert_hole_d` | 5.6 | 端盖 B 热熔螺母孔，按试打块改 |
| `main_wire_x` / `bplus_x` | None | 引出片 X，None = 端子片正中间 |
| `strip_w` | 20 | 连接片宽 |
| `series` | 16 组 | 串联顺序，两个端子都在最上面一层 |
| `rods` / `bolt_len` | 6 个星形位 / 150 | 螺栓位置、螺丝杆长（沉孔深度自动算） |

受力分析（无界面，较慢）：`freecadcmd fem_run_v3.py`，结果写入 `FEA/v3_results.json`。
